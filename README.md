# city-health-clinic-management-system
City Health Clinic Management System

About the Project

City Health Clinic is a simple clinic and queue management website developed as a CSE326 academic project.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

Features

- Doctor Profiles
- Patient Registration
- Appointment Booking
- Available Slot Checking
- Walk-in Token Generation
- Live Patient Queue
- Daily Schedule and Search
- Patient History

Objective

To make clinic operations more organized through a simple and user-friendly web interface.
